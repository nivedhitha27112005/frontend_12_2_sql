\- Handle button clicks.

\- Validate forms.

\- Change webpage content.

\- Easy to learn.

### **2. What is the difference between var, let, and const?**

&#x09;

&#x09;var, let, and const are used to declare variables in JavaScript.

&#x09;var: Can be redeclared and reassigned.

&#x09; let: Cannot be redeclared in the same scope but can be reassigned.

&#x09; const: Cannot be redeclared or reassigned.

&#x09;

There are two types:



1\. Primitive Data Types:

&#x09;String

&#x09;Number

&#x09;BigInt

2\. Non-Primitive Data Types:

### **4. What is a function in JavaScript?**



&#x09;A function is a block of code used to perform a specific task. It can be reused whenever needed.



There are three common types:



1\. Normal Function

2\. Function Expression

3\. Arrow Function



### **5. What is the difference between == and ===?**



Both are comparison operators in JavaScript.

\- == checks values after type conversion.

\- === checks both value and data type.

Example:

10 == "10"   // true



10 === "10"  // false





### **6. What is React.js? Why do we use it?**



&#x09;React.js is a JavaScript library used to build user interfaces and interactive websites.

##### 

##### **Why do we use React?**

To create websites easily.

To reuse components.

To update UI efficiently.

To manage webpage content.



### **7. What is a component in React?**



&#x09;A component is a small, reusable part of a webpage.



##### Examples:



&#x09;Navbar

&#x09;Header

&#x09;Footer

&#x09;Login Form



A functional component is a JavaScript function that returns JSX.





### **8. What is JSX in React?**



&#x09;JSX stands for JavaScript XML. It allows us to write HTML-like code inside JavaScript.



### **9. What is the difference between Props and State in React?**



##### Props:



&#x09;Props are used to pass data from a parent component to a child component.

##### 

##### State:



&#x09;State is used to store and manage data inside a component. When state changes, the UI updates.

##### 

##### Difference:



&#x09;Props are passed from parent to child.

&#x09;State is managed inside a component.	

&#x09;Props are read-only.

&#x09;State can be updated using a setter function.



### **10. What is Virtual DOM in React?**



&#x09;Virtual DOM is a lightweight copy-like representation of the Real DOM. It helps React update the webpage efficiently.
